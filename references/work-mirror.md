# 网站作品/资产全量镜像（离线化搬运）

> 适用：目标是把一个**作品托管站**（教育课件社区、H5 作品平台）的大量作品**原样搬到本地、断网可跑**——不是抽正文（scrape/crawl），也不是拉结构化记录（api-bulk-harvest），而是第五类活：**作品本体 + 全部依赖资产的离线镜像**。触发："把这个站的作品全扒下来离线用/套壳/搬到我们自己页面，不依赖源站任何服务"。

## 0. 开工前必须先想清楚（省两轮返工的关键）

**"下载完成"不等于"可离线引用"。镜像仓库 ≠ 可运行站点。** 交付前对照六条，缺哪条都不能宣称离线可用：

1. **作品本体全了吗**：列总数时按平台的**作品架构代际**拆分——同一社区常有旧代（服务端渲染直出 HTML）与新代（构建后的 bundle）两套形态，抓取方式完全不同，只扫一种会漏一半。
2. **作品引用的资产全了吗**：HTML 壳里写的 js/css、CSS 里的 `url()`、JS 里的相对路径、媒体/模型/字体子目录——**只解析 HTML 壳的 src/href 必漏 CSS 字体与相对媒体目录**（实测漏 337 个文件/1.3GB：作者上传的视频/glb 3D 模型/朗读音频藏在 `media/{uuid}/asset` 这类相对路径里）。
3. **引用改写了吗**：库和资产下到本地 ≠ 作品会用本地的。**零改写 = 仍然依赖源站**。HTML/CSS/JS 里的绝对 URL 必须批量改成相对本地路径。
4. **运行时服务依赖识别了吗**：表单提交、AI 生图/TTS、WebSocket、第三方 CORS 代理、iframe 嵌入——这些**没有静态等价物**，物理上无法镜像，必须逐件登记并让需求方定策略（保留外链/换自有服务/禁用该互动块），不能打包票"原汁原味全离线"。
5. **断网真机验收了吗**：不经过"本地静态服务器 + 浏览器断网渲染巡检"，不能下离线结论。
6. **元数据/索引建了吗**：作品目录名通常是无意义 hash/key，必须靠单独的元数据（标题/学科/作者/uuid）join 才能检索，资产本身不携带分类信息。

## 1. 摸清站点形态（只读侦察，先采样再放量）

- **登录后用 CDP 抓真实作品页的网络请求**，不要猜接口、不要只读 SPA 壳：`view/{uuid}` 页往往先打 `/open-target`（返回作品代际/真实载体 URL），再打详情接口，最后由前端跳到真实渲染地址（实测：SPA 壳 8KB 不含作品；真实旧作品在 `api.<域>/view/{uuid}` 直出自包含 HTML，新作品在静态域 `m.<域>/w/{projectKey}/` 的 bundle）。
- 列表 API 一页拉全量元数据（含 uuid/作品 key/代际 source/标题/标签/作者/热度），**这是后续分类与 join 的唯一索引**，单独存（jsonl）。
- **分代际各抽样 5-10 件实测**：确认每代的本体获取方式、平均体积、资产引用密度后再估总量工期，禁止用 1-2 件的印象外推几千件。
- **列表接口常有两套，口径不同，都要摸**：①公开精选/社区池（匿名可调，如 `public/community/opus?current=&pageSize=`，只收被官方选中的作品）；②登录态全量（需浏览器 cookie/JWT，覆盖全站含未入选作品）。实测同站两集合差集可达数百件（公开池有/全量列表无，反之亦然）。**不能拿一个接口的 total 当全站总量**；要分别记录两个 total、做集合差，缺口件用"view 页→`open-target` 匿名解析→真实载体 URL"补齐（该接口对新代作品返回 `kind=public_stable`+包地址，匿名即可，无需登录态）。
- **平台会对老代作品停止分发，这是源站侧行为不是漏抓**：`open-target` 对老代返回 `{"kind":"legacy","url":""}`（空载体），view 只剩 SPA 空壳、官方打包接口 404。抽样验证空 `url` 占比后如实报告"该代官方通道已关、只剩历史镜像/CDP 运行时抢救"，不要承诺能全量救回，也不要把它当我方失败返工。
- 资产清点要正则扫三层：HTML 的 src/href、CSS 的 `url()`/`@import`、JS 字符串里的相对资源与 `media/{id}` 模式；正则结果去噪（SVG 内部 `url(#渐变ID)` 锚点、模板串 `${...}`、JS 报错信息里的文档站域名 react.dev/github.com 等**不是运行时依赖**，勿当外链下载）。

## 2. 下载器纪律（大批量，几千文件/几 GB）

- **单线程 + 礼貌间隔（0.6-0.8s/个）+ 每 50 个休整 5s**。教育/云厂商对象存储前置 WAF，并发 3-4 即可在几分钟内触发 IP 封禁；串行 0.7s 跑几千文件零拦截（实测对照：并发下载同云系站点即刻被 WAF）。
- **熔断与普通 403 分开**：只有 `429/503` 与**真实文件路径**的 403 才整体停手；**目录前缀 URL（无文件名/以 `/` 结尾）被对象存储 403 拒绝列目录是正常响应**，记死链继续；第三方 CDN（图片站防盗链）的 403 也是死链而非封 IP。过严熔断会让一个目录 URL 白断整个任务。
- content-type + **文件头魔数双校验**：对象存储常出现 URL 扩展名是 `.png` 实际返回 JPEG；HTML 拦截页/占位页要能识破。下载后按真实魔数定扩展名，不要信 URL 后缀。
- 断点续传：每件 `ok/gone/fatal` 实时写 manifest（jsonl 追加），重跑读账本跳过；多棒接力时**启动前先对账本去重（同 URL 保留末条）**，避免两段运行期重叠产生重复下载。
- 大文件（视频/glb，几十 MB）`--max-time` 放宽到 300s；境内域 `--noproxy '*'` 直连，境外库走 socks5 并在开跑前自检代理存活。
- **跨作品共享文件只下一次再复制/硬链接**（公共字体、同 uuid 媒体被多作品引用）。

## 3. 进程编排（Windows 长任务，血训）

- exec/终端会话有生命周期（约 30 分钟空闲/会话结束即回收子进程）。**几小时的批量任务必须脱离会话启动**：`Start-Process pwsh -ArgumentList @('-NoProfile','-File','"带空格的完整路径"') -WindowStyle Hidden`——**路径含空格时参数必须显式加引号**，否则脚本静默不启动（任务管理器看不到进度、账本不动，排查浪费一整轮）。
- **等待接力要判断"真实工作进程"（python/node），不是外层 shell**：pwsh 可能先于其子进程退出，按外层 pid 判断"上一棒结束"会提前触发下一棒，造成同域名并发与重复下载。多棒最稳写法：**一个 pwsh 脚本内串行 await**（`Run A; Run B; Run C`），不用外部 while 等 pid。
- 脚本含中文路径时：`.ps1` 用 UTF-8 **with BOM** 并以 **pwsh 7** 执行（Windows PowerShell 5.1 按 GBK 读无 BOM 文件会把中文目录花成乱码）；被 python 调用的脚本本身保持 UTF-8 无 BOM。

## 4. manifest 对账本（硬要求，与 api-bulk-harvest 同口径）

- 每类下载独立账：作品清单（元数据 jsonl）、素材（url→本地路径/真实类型/尺寸/状态）、作品自带媒体（uuid→引用作品/类型/尺寸）、第三方库、运行时服务登记册、投毒/危险域名清单。
- 状态口径：`ok` / `gone`（源站 404，永久缺失）/ `fatal`（熔断）/ `badmagic`；死链区分"源站自己也 404（作者漏带，非我方责任）"与"我方漏抓"。
- 完成判据：账内 ok 记录**逐件磁盘存在性核对为 0 缺失**；账本行数去重后与目标数一致；体积用字节数交叉验证（PowerShell 的 MB 是 1e6、MiB 是 1048576，数字对不上先查单位再查丢文件）。
- **建增量基线防重复下载**：首扒后把公开池全量列表（uuid+标题+学科+日期+代际）落一份带日期的 baseline（如 `metadata/baseline/community-YYYYMMDD.json`）。以后更新只拉列表做集合 diff——新增 uuid 才进下载队列，存量不重下；全站全量口径需登录态，频率低于公开池、默认只读 diff 不自动下载。配一个 `incremental_check` 脚本即可，避免"再扒一遍全站"（类比帧理每日只吃 backlog）。

## 5. 离线化与验收（搬运只完成了一半时）

- 写 URL 改写器把绝对引用改本地相对路径（HTML/CSS/JS 三栈），**先建黄金断言集再改**：拿已下载样本断言"改写后无 http(s) 绝对引用、相对文件全部存在、页面关键交互文本在"，TDD 跑通再批量。
- 清洗：第三方投毒域名（如 polyfill.io 被收购后投毒，现代浏览器无需其 polyfill）删 `<script>`；平台注入的 telemetry/postMessage 上报段评估剥离；占位标题（"作品 N 号"）按元数据改名。
- 第三方公共库（cdnjs/unpkg/Google Fonts）单独镜像，CSS 要**递归解析内部字体 URL**（@font-face 的 woff2 在下一层）。
- **最终验收 = 本地静态服务器 + 无头浏览器断网批量巡检**：console 错误、失败请求数、空白渲染（像素直方图）、关键控件存在；全量机器巡检 + 抽样人审。这一步不做，"离线可用"只是口头结论。
